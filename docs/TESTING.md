宿主 DEX 执行器以 Java 反射执行平台外部调用，以显式替身承担 Android 调用。数据流检查覆盖寄存器初始化与基本类别；成员检查覆盖已打包类的链接和继承。

## 手机验收

目标设备为一加 12 / ColorOS 16。先覆盖安装 r5，再完成以下顺序：

1. 结束应用进程后启动，观察组合标识、底部声明及浅深色背景。
2. 在主课表进入上大教务；登录后打开个人课表，再进入导入流程。
3. 退出教务、重新进入，检查学校会话；通过登录管理清除状态，再验证重新登录。
4. 打开选课页面、功能设置与时钟，观察每个入口的返回路径。
5. 检查默认作息升级，核对既有课程、周次、课表关联与手动时间。
6. 查看桌面组件、锁屏提醒、重启恢复，并在一致场景下测量资源占用。

将手机型号、系统版本、操作步骤、现象和对应时间记录到 Issue；涉及认证资料时先完成脱敏。

## 构建复现

```bash
python build.py --test
python tests/run.py dist/WakeUp_6.0.23_SHU_r5.apk
```

测试生成的报告位于 `build/tests/report.json`。发布时保存 APK、报告与版本说明，签名材料继续保存在仓库外。
