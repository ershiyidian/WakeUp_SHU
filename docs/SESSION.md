# 登录会话

教务：<https://jwxt.shu.edu.cn/>

选课：<https://jwxk.shu.edu.cn/>

首次打开教务入口后，在学校页面完成统一身份认证。选课站点继续执行它自己的学校认证跳转。应用中的两个 WebView 入口共享浏览器 Cookie 存储，Cookie 的域、路径、Secure 标志及有效期按站点设置处理。

普通退出保留会话并释放网页对象；重新进入时，WebView 使用仍在有效期内的 Cookie。学校会话到期后，页面引导重新认证。

“上大教务 → 登录管理 → 清除登录状态”清除当前应用 WebView 的 Cookie 与 WebStorage，然后回到教务首页。原设置中的手动浏览器清理功能继续可用。清理操作作用于应用内的浏览器数据。

使用导入按钮时，当前课表 ID 通过原有参数传给导入 Activity。导入页面退出后的自动 Cookie 清理调用已移除，页面资源清理流程继续执行。

公开协作使用合成课表、步骤说明与脱敏日志。账号、验证码、密码、Cookie 和签名密钥放在各自设备或私有存储中。
