# 授权范围与来源

源码提供与公开再分发分别按以下范围管理。

| 内容 | 来源 / 授权 |
|---|---|
| `app/src/main/java` 中的上大扩展与兼容入口 | WakeUp_SHU 新增实现，MIT |
| `tools`、`tests` 与构建入口 | WakeUp_SHU 新增构建和测试实现，MIT |
| `core` 中继承的 WakeUp 6.0.23 业务与依赖代码 | 由用户提供 APK 重建；适用各原权利人的授权；完整继承部分的公开再分发授权待权利人确认 |
| 继承布局、图片、学校目录及其他原应用资源 | 适用原资源的权利与授权范围 |
| 上海大学名称、校徽 | 学校标识，来源为用户提供图片；公开使用按学校标识规范与授权处理 |
| BUPT 参考项目 | 设计参考；该项目自身基于 WakeUp 3.621，采用 Apache-2.0 |
| Greasy Fork 参考脚本 | 交互参考；两份查阅脚本均标注 MIT |

MIT 文件覆盖本表明确列出的新增实现。完整的 6.0.23 继承工程用于本次源码重建和个人研究交付。计划公开整个继承工程时，先取得对应权利人的再分发授权，并保留各组件原有署名与许可。

公开仓库可先发布已明确采用 MIT 的新增代码、工具、测试与文档，再按照取得的授权扩展继承内容。校徽与原应用资源的授权独立记录。

项目署名保留 WakeUp 原作者及参考项目作者，详见 `docs/SOURCES.md`。
